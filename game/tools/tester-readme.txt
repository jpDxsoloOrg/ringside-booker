Ringside Booker {{SEMVER}} (Alpha) for Windows
===============================================

Thanks for testing! This is an early Alpha build, so expect rough edges.

Run it
------
1. Unzip the whole folder anywhere you like, for example your Desktop.
2. Open the folder and run RingsideBooker.exe.
3. Windows may warn about an unknown publisher, because the build is not signed yet.
   Choose "More info", then "Run anyway".

You need 64-bit Windows 10 or 11.

Your saves
----------
Saves live outside this folder, in:
  %USERPROFILE%\AppData\LocalLow\jpDxsolo\Ringside Booker\Saves
Deleting or replacing the game folder never touches them.

Alpha saves may not load in the next version. If one won't load, start a new game.

Update to a new build
---------------------
Delete this folder (or unzip the new one next to it) and run the new RingsideBooker.exe.
Your saves stay where they are.

What's in this folder
---------------------
- RingsideBooker.exe and RingsideBooker_Data: the game.
- CHANGELOG.md: what changed in each build. The game also shows it under What's new.
- LICENCES.txt and licenses: the licences of the software the game uses.
- version.json and version.txt: exactly which build this is ({{VERSION}}).

Tell me what you find
---------------------
When something breaks or feels wrong, note what you did, what you expected and what
happened, and send it with the version above.
