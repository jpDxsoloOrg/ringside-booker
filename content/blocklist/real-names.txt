# Real-name blocklist for tools/validate-world.
#
# Names of real performers, promotions, shows, events, titles and networks that must never appear
# in Ringside Booker content. `npm run validate:world` checks every person, ring, promotion, brand,
# title, venue, network, event and team name against this list and fails on any match.
#
# Format: one name per line. Blank lines and lines starting with # are ignored. Matching ignores
# case, accents and punctuation. A one-word entry only matches a name that is exactly that word
# (a leading "the" and trailing numbers are ignored); a one-word entry in capitals (an acronym such
# as WWE) and a longer entry also match inside a longer name. See tools/validate-world/README.md.
#
# A one-word name that is also an everyday word ends with the flag [case] (`Sting [case]`). It
# then matches only as written here or in capitals, so the blog checker passes "a loss to sting
# less" but still flags the capitalised name. The world validator and the blog checker share
# one matcher (tools/validate-world/src/realNameMatcher.ts), so both read the flag the same way.
#
# This file is data for the checker only. It lives outside every pack and is never loaded by the
# game. When you spot a near miss in content, add the real name here.
