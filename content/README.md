# Content

The world the game ships with: the fictional promotions, workers, titles, regions and the base
data packs (gimmicks, finishes, match stories, random events, balance numbers), all as JSON.

Content is data, not code. Anything here can be edited, replaced or extended by a data pack
without touching the engine, and every file is validated against the engine's zod schemas when it
is loaded.

Everything in this folder is original and fictional. Any resemblance to real people or companies
is a coincidence.
